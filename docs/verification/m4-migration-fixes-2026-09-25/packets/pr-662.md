## Infrastructure and observability weaknesses

- The user-facing error ("I encountered an error. I saved the partial history…") does not say that a complete answer existed in the history. Before this fix, an operator could not tell a lost answer from a real failure without the daemon log.
- No e2e scenario covers an empty model reply. The scripted daemon provider cannot produce `ModelEmptyResponse`, so this path is only reachable with an Ollama stand-in like `evidence/rig/fake_ollama.py`.

## Monitoring delta

Proposed, not added: count the log line "empty response to the task_complete reminder — delivering the previous answer". A rising rate means the model often ends with silence after the reminder, which argues for the separate decision on skipping the reminder for Complete-classified EndTurns.
